# EP001 作画監督へのカット別依頼

[絵コンテ準備稿](storyboard.md)と[ショット台帳](../../episodes/ep001/shots.csv)に対応。以下は #20 の仮要求を具体化した依頼ID。正式素材の `asset_id` とパスは作画台帳で対応付ける。配役・基準画像・デザイン一次承認を確認後、G2aで合意した範囲を制作。現段階では差分数・角度・遮蔽の実現性を確認してほしい。カットIDにはすべて `EP001_` が付く。

| 依頼ID／#20対応 | 対象カット | 必要な素材・受入条件 |
| --- | --- | --- |
| EP001_BG01 / REQ-B01 | SH010–090 | 同じ夕方の玄関、通常廊下、敷居、マット。Aの壁・戸枠・足位置を固定し、24.08秒前後で光と手前の位置が跳ねない。B/C/Dは同じ側から切り出す。 |
| EP001_BG02 / REQ-B01+B02 | SH010・020・050・070 | 戸枠奥の廊下の遠→中→近のレイアウトと同一意匠の居酒屋入口。SH020は床目地と奥壁の位置がのれんと同期。SH070の通常廊下と敷居の継ぎ目を揃える。 |

| EP001_PR03 / REQ-P02 | SH010・020・040・060・070・080 | スマホ本体と画面を分離。左手の持ち姿と共通支点。M01–M06の文面は映像側の文字レイヤーに渡す。 |
