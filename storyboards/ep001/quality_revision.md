# EP001 試写の演出改訂案

対象は冒頭 SA01 と、最大の風船から持ち帰りまでのオチ（SA04後半・SA05）。[脚本](../../episodes/ep001/script.md) と [ショット台帳](../../episodes/ep001/shots.csv) に合わせ、仮の人物デザインと台詞の時間窓を使用する。1080×1920、24fps。各範囲は先頭を含み末尾を含まない。

## SA01　口から出たと分かる3秒

固定の胸上寄り。客の頭と肩を画面の中央より左に置き、口が向く右上を風船の通り道として空ける。画面下のカウンター上辺とそこに着く肘を日常の手がかりにする。背景は暖色の壁と奥の窓の明度差を使い、窓枠や棚の線を口と浮上経路から外す。店員と追加の小物は次のカットで見せる。

| 秒／フレーム | 画面と芝居 |
| --- | --- |
| 0.00–0.75／0–18 | 客は首が前に出た姿勢で視線を落とす。肘をカウンターに着け、体重が移って肩が沈む。手首を軽く曲げて重さを出す。 |
| 0.75–1.50／18–36 | 口を吐息の形に開く。開口の外縁に触れる小さな輪郭からF1を膨らませる。発生点は止め、風船の外側だけが右上へ広がるようにする。 |
| 1.50–2.25／36–54 | 輪郭が口を離れ、F1が右斜め上に浮く。まず瞳が風船を追い、眉が遅れて上がり始める。肩と肘は固定。 |
| 2.25–3.00／54–72 | 眉が上がったあと頭がわずかに起きる。口は開いたまま、視線がF1に合うところで一拍止めて次へ。字幕は出さない。 |

## SA04～SA05　最大の風船と持ち帰り

同じ視線軸のまま、カウンターの上辺と前板、端の通路、明るい入口の枠を画面に残す。カウンターの端から入口まで床を見せ、店員が端を回る間は腰または足を読める引きにする。通路は画面中央寄りから右奥へ抜ける。四個は入口側、二人の顔は反対側に置く。背景の小物は奥にし、ドア枠と床・カウンターの境界で店内の奥行きを見せる。

| 秒／フレーム | 画面と芝居 |
| --- | --- |
| 25.00–27.25／600–654 | カップから店員の手が離れて肩が落ち、F4が口元で膨らむ。離れたら顔の横へ早めに抜き、吹き出し前の客の顔も残す。 |
| 27.25–30.00／654–720 | 目の高さ付近でF4を止めて見せる。全四個の外周をずらし、客の瞳がF4へ移る。客の作り笑いの口角がいったん落ち、眉と肩が緩む。 |
| 30.00–34.00／720–816 | A05の頭で客が吹き出し、顔をF4から店員へ向ける。店員の表情は小さな半笑いに留める。客はF1・F2を保持し、F3は頭上を緩やかに上がる。 |
| 34.00–36.00／816–864 | 店員はF4を片腕で誘導し、カウンターの右端を回る。姿勢を入口方向に向け、視線だけF3を追って次の動作を予告する。 |
| 36.00–38.25／864–918 | 客がF1・F2を横から寄せ、店員が空いた手でF3を上から受ける。F4を合わせ、前腕が触れてから四個の移動方向が揃う。 |
| 38.25–40.50／918–972 | 店員は前腕で風船の上を押さえて進む。手の空いた客はカップを取り半歩遅れて続く。店員の肩は進行方向のままで顔だけ客に向け、A06を言う。字幕枠は x=120〜840、y=1320〜1550。 |
| 40.50–42.00／972–1008 | 入口の手前で互いに視線が合い、店員の半笑いに客が自然に笑う。四個の並びと顔を読める1.5秒を残し、境界を越える前に切る。 |

## 改訂試写で確認すること

- **冒頭**　音声と字幕を切り、幅約360pxで最初の3秒だけを見せる。説明を聞いていない視聴者に「何が、どこから出たか」「客がそれに気づいたのはいつか」を聞く。口元から風船が出て、客がそれを見上げたと説明できれば通過。
- **オチ**　同じ表示サイズでSA04～SA05を無音・字幕なしで見せる。F4が最大で店員から出たこと、店員がカウンター端を回ったこと、二人が四個を入口に運んで笑顔になったことが伝わるか確認する。
- **コマ送り**　冒頭の発生点から浮上まで輪郭を追えるか、SA04の比較中とSA05の最後に風船四個を数えられるか、受け取る手や押さえる前腕が風船に触れてから束が動くかを見る。顔・手・字幕の重なりは通常速度と静止画の両方で確認する。
- **未実施の確認**　初見者試写と端末上の字幕確認は改訂動画で行う。尺と発話窓は脚本の値を使用し、ここに示した途中の姿勢と画面配置は仮編集で調整できる。
