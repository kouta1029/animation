## 仮UIとテスト

安全領域の仮モデルは x=16〜300、y=64〜512（360×640）。実YouTube UI仕様ではない。メッセージは16px（1080基準48px）、貼り紙15px。左右の吹き出し位置・上段下段の区別を設ける。文字幅は1字16pxの保守的概算であり実グリフ計測ではない。

| 2導入×3間隔×840フレームのモデル検証（HTML内 tests() をJSで実行） | PASS: 17,880 assertions。キュー境界・仮UI内の吹き出し・概算文字幅・出現消失・L02終端 |

初見テスト手順：字幕OFF、音なし、35秒を一度だけ再生。①返信と出現 ②遠さ解消 ③部屋着歓迎 ④拒否と消失 ⑤誘った側の本音を口頭で再現できるか記録。別々の初見者で導入A/Bを比較し、冒頭3秒で①を読めるか優先。字幕ONでは発話文字が顔と戸口を隠さないか確認。間の3案は音声実測後に別途比較。合格は人の視聴結果で判定し、本ロジック検査のみで宣言しない。
