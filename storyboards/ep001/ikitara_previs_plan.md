# EP001「行けたら行く」演出試作指示

PR #18 の `c525b5540462a7eda5701b9b9f9a1ec4591eeb36`、[企画](../../episodes/ep001/brief.md)・[脚本](../../episodes/ep001/script.md)を参照。G1前の画面とタイミングの検討。正式コンテとショット台帳はG1承認後に作成する。9:16、24 fps、想定35秒。開始を含み終了を含まない。

| 仮尺 | 構図と芝居 |
| --- | --- |
| 0.00–3.00 | 最初から誘いの短文を表示。0.90秒で親指を押し込み、「行けたら行く」が送信済み側に出る。同軸の肩越しに切り替え、文面は戸口を避けた位置に短時間残す。戸の先でのれんを初めて見せ、手が止まる。返答と出現を同じ瞬間に重ねず、初見で順序を追えるようにする。 |
| 3.00–12.00 | 戸枠・主人公の足元を固定する。遠いという返信の直後、廊下の奥行きが縮み、のれんが戸枠で止まる。主人公は足を動かさず、肩と頭が一拍遅れてのけぞる。「近っ」の字幕は動きが止まってから。 |
| 12.00–22.00 | 袖をつまむ手元で部屋着を先に見せる。閉める戸の端を画面に残し、貼り紙が変わったら手を止める。視線を貼り紙→袖→貼り紙と移す。貼り紙は文面が読めるサイズで止める。 |
| 22.00–29.00 | 指を短く止め、断る文面を送信。冒頭と同じ戸枠・目線で普通の廊下に戻ったことを見せ、肩を緩める。 |
| 29.00–35.00 | 「助かる。俺も今、布団」は改行位置で意味が自然につながるように表示。返信は29.00〜32.10秒。顔に戻って0.50秒ため、32.60〜34.60秒で無表情にツッコむ。台詞の後に0.40秒残し、切る。幹事の姿は出さない。 |

## 受入条件

- 1080×1920を幅360pxに縮小し、縦型プレーヤーのUIを想定した位置で再生する。下端・右端と顔・戸口を避け、二つのメッセージが別話者のやり取りに見えるようにする。実端末でUIと重ならないかを後で確認する。
- 音声と発話字幕を消し、物語内のメッセージと貼り紙だけ残して初見者に一回見せる。冒頭3秒で「何と返したらどこに何が出たか」を説明できること。文字の滞留が足りなければ、スマホと戸口を同じ画に収める案を比較する。
- 同じ条件で全尺を見る。「遠い」が解消され、部屋着まで歓迎され、断ると廊下が戻り、誘った人も行く気がなかったという順序を読み取れること。終盤は返信を読み切るタイミングと主人公の一拍を別々に確認する。
- 初見者、実端末、音声実測は未実施。G1後、演出から作画へ戸と戸枠の別レイヤー、遠近差のある廊下、のれんと貼り紙、スマホと袖の専用ポーズを依頼する。映像担当へは固定戸枠の遮蔽、文字の安全位置、L01・L02の音声尺と字幕同期を連携する。
