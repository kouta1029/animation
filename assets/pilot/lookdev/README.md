# EP001 SA01 冒頭の作画基準案

内部スタイルフレームは、客の疲れと風船の異常を同じ画角に収めるための試作。客・店の外見は仮。画像生成による内部検討用素材で、利用条件と商用利用の権利確認は未実施。リグや納品素材としての採用は保留。

- **構図**　左の余白に口元から離れた風船、右に客の顔。肘の接地と肩のラインを同時に入れる。背景は棚・窓・カウンターの少数の面で喫茶店だと読ませ、顔と風船に最も強い明暗差を置く。
- **芝居**　肘を置く → 体重が乗って肩が沈む → 息で口が開く → 口元で風船が膨らむ → 瞳と片眉が風船を追う。口、視線、眉の変化に時間差をつけ、疲れから驚きへの変化を見せる。
- **映像担当への受け渡し**　カウンターと肘の接点を固定し、首・肩・瞳・眉・口・風船を個別に動かす。風船の発生と浮遊を同じ画角でつなぎ、無音で因果が読めるかを幅360px程度のスマホ相当表示でも確認する。

脚本参照は `episodes/ep001/script.md` の SA01（00.00–03.00、A01）。この一枚で確認できるのは画角、コントラスト、表情と姿勢の読みやすさ。演技の動き、手指と肘の接地、風船の発生から浮遊までの連続性は動画側で確認する。

941×1672のPNGを360px幅に縮小して目視確認した。カウンターに体重が乗った肘と下がった肩、半開きの口、上に向いた視線、風船の輪郭と結び目を同じ画角で判別できた。静止画の息の軌跡は発生の位置を補う描写。動画では口元の輪郭の成長と離れる動きで因果を示す。

総監督確認：画像の暖色光、奥・中・手前の明度差、肘の接地のみを次稿の参考にする。人物の描写はシリーズで検討中のデフォルメより写実寄りで、風船が抜ける方向も演出案とは逆。次稿の設定画・レイアウトには採用しない。
