# EP001「ため息、持ち帰りで」仮素材

会話中心のリミテッド2Dの検証用。仮の客と店員を用意した。既存キャラの配役・正式デザインは未決定。外部画像・フォント・生成PNGをこれらのSVGには使用していない。

| 素材 | 座標・使い方 |
| --- | --- |
| `background.svg` | 1080×1920。店員を左、客を右。入口は右奥。カウンター天板はy=1089。 |
| `counter_foreground.svg` | 背景と同座標。店員の下半身を隠したいときに手前へ重ねる。 |
| `customer_*`、`clerk_*` | 共通320×420透過。左上を揃え、`body → arms → eyes → mouth` の順に重ねる。各カテゴリから一枚を選ぶ。 |
| `balloon.svg` | 180×215透過。大中小は拡縮し、人物・メニュー立てとの前後レイヤーを切り替える。 |
| `coffee.svg`、`menu.svg` | 84×108と126×170の透過SVG。カウンター上または手の前に配置する。 |

口の中心座標は客（149,159）、店員（171,159）。足の基準はy=403。個別の腕・首の関節調整は正式リグの段階で切り分ける。

| 演技 | 目・眉 | 口 | 腕 |
| --- | --- | --- | --- |
| 息を吐く | `closed` | `open` | `elbow` または `rest` |
| 風船を追う | `up` | `closed` または `open` | `reach` |
| 風船を囲う | `up` または `normal` | `closed` | `gather` |
| オチで笑う | `normal` または `closed` | `smile` | `rest` または `gather` |

作業パスは `assets/pilot/animatic/`。G2では絵コンテで指定した左右3/4、表情差分と遮蔽を確認し、映像担当の会話試写とあわせて判断する。
