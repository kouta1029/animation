# EP001冒頭3秒・画質と芝居の試験

42秒のアニマティックで指摘のあった画面の奥行き、身体の動き、風船の出どころを、SA01の固定カメラで検証する。画・動き・試験音はこのフォルダのコードで生成する。喫茶店の縦窓、カウンター上面・前面、人物を別々の面として描き、窓光と衣服の陰影をつけた。作画監督の参考画は構図、光、接地の資料として参照し、画面素材としては使用していない。

| フレーム（0始まり） | 芝居 |
| --- | --- |
| 0–17 | 前腕をカウンターに下ろす。接地の後、肩と頭を時間差で沈める。 |
| 18–35 | 開口を保ち、頭の回転を反映した口の座標を起点に風船が膨らむ。 |
| 36–53 | 風船が口から離れ、客の視線が遅れて追う。 |
| 54–71 | 白目・眉の変化、頭の持ち上げを重ね、驚きが残る位置で切る。 |

演出改訂メモでは顔の外へ上げる動きとしている。試作は客を右、風船を左上へ配置し、口から離れた後は顔の外側を通す。画面右に残る目・眉・肩と、左へ移る風船を一画面で読ませるための変更。

## 再現

```bash
bash animation/pilot/quality_probe/render.sh /tmp/EP001_opening_motion.mp4
```

Godot 4.7.2が元の解像度でSVGをラスタライズし、FFmpegが1080×1920・24 fpsでH.264/AACを出力する。Pythonで生成した環境音・息・接地の試験音を使用する。出力済みパスを指定したときは処理を停止する。動画と比較画像はGit外で共有する。

この試験の範囲は冒頭3秒。続く場面に反映する場合は、作画・演出担当と口形、人物の角度、喫茶店の配置を揃え、オチの芝居と入口への動線を別ショットで検証する。
