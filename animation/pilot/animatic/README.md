# EP001「ため息、持ち帰りで」レビュー用アニマティック

脚本とコンテのタイミング、風船の連続性、スマホでの字幕位置を確認するための42秒試作。参照は [G1脚本](../../../episodes/ep001/script.md)、[ショット表](../../../episodes/ep001/shots.csv)、[作画仮素材](../../../assets/pilot/animatic/README.md)。制作資料の参照コミットは `096bc9f4847acfb00fd5b7c9fecca20a1052f81f`。

## 再現

リポジトリ直下で以下を実行します。対象のMP4は存在しないパスにしてください。動作環境は Godot 4.7.2、Python 3、libassとlibx264を備えたFFmpeg、Noto Sans CJK JPです。

```bash
bash animation/pilot/animatic/render.sh /tmp/EP001_review.mp4
```

ヘッドレスのGodotが、透過SVGをラスタライズし、動作・表情・風船の位置を24fpsのフレームごとに合成します。連番PNGを一時領域に出し、FFmpegで1080×1920に拡大して字幕と試験音を合わせます。出力後は映像と音声を最後までデコードして検査し、一時ファイルを削除します。再生用MP4はGit外で共有してください。

台詞タイミング用の試験音はPythonで生成した音程パルス、ため息は帯域を絞ったノイズ、風船出現には短い効果音を使っています。日本語の内容は画面の字幕で確認できます。口形の開閉は予定キューに基づく仮動作です。G3以降に、承認済みの話者・音声素材から読み、感情、モーラと口形を確認して調整します。

ショット境界は0・72・264・528・816・1008フレーム。風船は発生順にF1〜F4。F1は口元から上がり、F2とF3は客が隠そうとする間に増え、F4は店員の長いため息で生まれます。終端の出入口では四つすべてを保持します。仮素材は正面中心で、歩行は位置・上下の移動で表現しています。

## 試写・再審査

- 字幕を隠した無音試写で、口元から現象が始まること、F4が最大であること、終わりに四個を持ち帰る意図が伝わるかを確認する。
- カウンターを回って入口まで進む動線と、前腕で風船を受ける動きは簡易表現。左右3/4、詳細な腕・手の切り替え、関節や重なりの破綻、手元と風船の接触は本素材とコンテで審査する。
- 実際にShortsプレーヤーが重なった状態で顔・風船の識別と字幕の長さを確認する。音声の言葉・感情・同期、本編素材のG2審査、16:9画角の再構成は今後の試験対象。

## 今回の試験結果

- 最終試作は42.000秒、1080×1920、24 fps、1008フレーム、H.264とAAC 48 kHz。全編の映像・音声デコードに成功し、復号したPCMでは試験音の有無を11区間で確認した。ピークは16 bitの8224でクリップを検出しなかった。
- 12点のフレームを照合。SA01は胸上の寄りで0.75秒の開口、1.05秒の口元の風船、2.75秒の上昇を確認。3秒で二人画へ戻る。F4は25.54秒付近で半透明の輪郭が顔と重なるが、26.04秒で顔の斜め上へ抜ける。最大の風船を含む四個を最後に確認した。冒頭の試作表示は2.75秒付近で風船と一部重なる。
- 独立した16:9構図の試験に先立ち、初稿のSA04の3秒を縦横比を維持したまま1920×1080に収め、H.264/AACに変換・全編デコードできることを確認した。横構図用のカメラ、字幕配置と余白は今後の設計対象。
