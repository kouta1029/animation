# EP001「行けたら行く」映像技術の事前確認

G0承認後、G1前の技術検討。入力は [PR #18](https://github.com/kouta1029/animation/pull/18) の `c525b5540462a7eda5701b9b9f9a1ec4591eeb36`、[企画ブリーフ](../../../episodes/ep001/brief.md)、[脚本](../../../episodes/ep001/script.md)。画角と文字の位置、仕上げ用素材、音声の採否は各工程で確認する。

## 戸枠とのれん

Godot 4では玄関を固定し、廊下・店の奥行き・のれん・貼り紙 S01 を戸口内のノードにまとめる。正面なら `Control.clip_contents`、斜めの戸口なら開口形状に合わせた `CanvasItem.clip_children` のマスクを候補にする。戸枠・開く戸・手はマスクの外で前景に描き、クリップ配下の多重マスクが必要なら描画を分ける。

- **出現**。M02送信から戸を開くまでを一続きにし、のれんは閉じた戸の向こうに待機させる。戸を開けた時点で廊下の奥に見える。
- **接近**。M03送信を開始キューにし、廊下の床の目地または奥の消失点に沿って、店レイヤーを位置・スケールで近づける。停止時にのれんの上辺を戸枠へ揃え、袖や手と前後関係が逆転しないようにする。カメラを固定する案を先に試す。
- **消失**。M05送信を切り替えキューにし、店・のれん・S01を消して通常の廊下へ戻す。戸の角度、戸枠と取っ手、人物位置を保つ。カットから直接再生しても同じ状態になるよう、各カット初期値を明示する。

受入確認は開始・接近途中・停止・消失の4状態。のれんや文字の戸枠外への漏れ、手との遮蔽、停止時の浮き、消失後の残像がないことをフレーム送りで見る。

## 縦画面の文字と情報の順序

1080×1920から360×640へ縮小して確認する。M01とM02は短いメッセージ表示として重ね、送信後も返信を保って戸の異変と因果がつながるか確認する。M06は「俺も今、布団」まで読ませてからL02のツッコミへつなぐ。S01は戸口にある貼り紙で見せる。メッセージ、貼り紙、L01・L02の発話字幕は別レイヤーで管理する。

48pxの日本語フォント、横幅660pxの本文領域を仮値にする。余白と吹き出しを含めて戸口、表情、右の操作列、下の説明欄と重ならない位置へ調整する。実際のShorts表示は端末により変わるため、演出監督と縦画面の端末表示を確認する。無音の初見試写では「何と返信したらどこへつながったか」「誘った側の本音は何だったか」を聞き、文字を見直さなくても意味が伝わるかを判定する。

M01〜M06とS01は画面文字。幹事の台詞音声は不要。G1承認版の発話IDと演技指示を受け取り、権利が確認できる候補で同じ2発話を比較し、実際の発話開始・終端・無音を計測して演出に渡す。音声ごとにサービスまたは録音元、利用プラン、話者・モデル／版、商用可否、表記義務、用途制限、規約URLと確認日、本人同意の要否を記録する。規約は提供元と個別音声モデルの両方を確認し、採用候補を `audio_manifest.csv` に結び付ける。G3までは試聴・尺確認用として仮と明示し、仕上げ版の音声参照先や公開物へ混ぜない。

## 先行確認結果

| 項目 | 判定・確認範囲 |
| --- | --- |
| 矩形クリップの座標モデル | **PASS**。Godot 4.7.2ヘッドレスのCPU `Image` で360×640の代理図形を描画。`Rect2i(80,100,200,350)` と遠方 `Rect2i(145,190,70,90)`／接近 `Rect2i(30,80,300,180)` の交差部分のみを店舗色で塗り、戸枠を前景に再描画。遠方・接近・消失で開口内、戸枠、外壁の11ピクセルを照合した。一時コードは `/tmp` で実行し削除済み。 |
| 文字幅 | **PASS（字送り幅のみ）**。Pillowの `ImageFont.truetype(..., 48, index=0).getlength(text)` を使用。Noto Sans CJK JPで M01 384、M02 288、M03 336、M04 240、M05 528、M06 480、S01 240px。全件が仮本文幅660px内。吹き出し・字幕との重なりと初見の読みやすさは実表示で確認する。 |
| GodotのCanvasItemマスク実描画・端末での無音可読性・候補音声の生成／試聴 | **NOT_RUN**。座標・字送りの確認範囲外。G1後、演出の画角と発話IDを受け取って代表カットで検証する。 |

本制作に入る時点で、G2承認済みの絵コンテ・`shots.csv`・`asset_manifest.csv`、G3承認済みの音声データを照合する。最終の出力確認は画角・フレームと実再生、表示切れ、欠損フレーム、音割れ、発話字幕の同期を分けて `qa.md` に記録する。
