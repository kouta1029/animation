# EP001「『行けたら行く』が通じない日」G1提出脚本

**G1審査待ち。** 縦9:16、想定35秒。夕方、自宅の玄関。主人公は部屋着でくつろいでいる。幹事はメッセージだけで登場。配役と店名は仮。[G0ブリーフ](brief.md)

## 本編

| 秒 | 画と芝居 | 発話・画面の文面 |
| --- | --- | --- |
| 00–03 | 玄関の戸口にいる主人公。誘いのメッセージは冒頭から表示し、返信をその下に出す。送信に続いて戸を開けると、廊下の先に居酒屋ののれんが揺れる。返信を画面に残したまま異変を見せ、戸を持つ手が止まる。 | M01・M02 |
| 03–12 | 主人公は一度スマホを見て、断る理由を打つ。送信すると、伸びていた廊下が縮み、のれんが戸枠にぴたりと収まる。主人公は上体だけのけぞる。 | M03・L01 |
| 12–22 | 部屋着の袖をつまみ、次の理由を送る。戸を閉めかけたところで店の貼り紙が「部屋着歓迎」に変わる。貼り紙と袖を見比べて固まる。 | M04・S01 |
| 22–29 | スマホに視線を落とす。親指を一拍止め、断りの返事を送る。のれんと貼り紙が消え、いつもの廊下に戻る。肩の力が抜ける。 | M05 |
| 29–35 | すぐ返信が来る。主人公はスマホをのぞき込む。返信を読ませてから顔へ切り返し、目線を落としたまま一拍。低く突っ込み、語尾の反応を残して切る。幹事の姿は映さない。 | M06・L02 |

## 脚本セルフチェック

- 目視確認済み。誘いへの返答、二つの言い訳、明示的な拒否の順で異変が進む。幹事の本音は最後の返信で明かす。
- 35秒は区間の合計。話者の試読とスマホ表示での読み取りは未実施。冒頭3秒の二つの短文と、最後の返信からツッコミまでの間をG1で確認する。
- G1後に演出へ渡す検証点は、文字を表示する位置・大きさ、のれんが迫る距離、戸を閉めかけてから貼り紙を二度見するタイミング。音声担当へは発話L01・L02のみを渡す。
