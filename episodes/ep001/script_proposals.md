**G0審査用の仮案。** 9:16、30〜60秒。登場人物は役割名で記載し、シリーズの正式キャラクター、店名、現象の周期は人間の承認後に扱う。尺はセリフ・動作・間を含む編集前の見積もり。

## A案「ため息、持ち帰りで」 — 42秒

**日常の目的**　仕事帰りの客は、行きつけの喫茶店で平静を装ってコーヒーを一杯買いたい。店員はいつも通りに注文を取りたい。

**今回の異常**　店内で人がため息を一回つくたび、口元に半透明の風船が一個現れ、ゆっくり浮かぶ。大きなため息からは大きな風船が生まれる。風船は手で寄せられ、店外にも持ち出せる。発生の終わりは画面外で、この一話では二人が自分のため息を笑えるようになったところで閉じる。

| 時間 | 画・動作 | セリフ・演技 |
| --- | --- | --- |
| 00〜03秒 | 客がカウンターに肘を置いてため息。目の前で風船が膨らみ、目線がつられて上がる。 | A01 客「……はぁ」疲れた息。 |
| 03〜11秒 | 客がいつもの笑顔を作る。店員は注文を待ちながら、客の真上の風船を見る。 | A02 客「いつもの。いや、今日は元気です」後半だけ声が上ずる。 |
| 11〜22秒 | 客は一個をメニュー立ての裏に押し込む。片手で押さえて安堵した瞬間に二個目。二個を寄せようとして三個目。腕が足りなくなり、笑顔のまま固まる。 | A03 客「よし……はぁ」息が漏れるたび視線だけが上に動く。三個目は無言のため息。 |
| 22〜34秒 | 店員がコーヒーを差し出しかけ、紙カップを置いて自分も長くため息。客の三個より大きな風船が二人の目の高さを横切る。客は笑顔を作るのをやめ、吹き出す。 | A04 店員「……はぁーー」平然と、長く。A05 客「そっちの方が大きい」笑い混じり。 |
| 34〜42秒 | 店員が大きな風船と客の三個を腕で寄せ、入口の方へ一緒に運び出す。客は紙カップを持ってついていく。 | A06 店員「全部、持ち帰りで」注文を確認する口調。二人の間を一拍見せて終わる。 |

**感情の流れ**　客は疲れ → 取り繕い → 露見の焦り → 安堵。店員は仕事の無表情から、大きなため息を経て小さな半笑いへ。一つ目と最大の風船を対比させ、字幕なしでも最後の反転を読めるようにする。

**概算素材**　喫茶店のカウンターと入口を含む背景1枚、キャラ2体、紙カップとメニュー立て各1、半透明風船1種を大小に拡縮して増殖、ため息の音3種類。優先差分は客の作り笑い・焦り・自然な笑い、店員の無表情・息・半笑いと、両腕で風船を寄せるポーズ。風船は前後の重なりを切り替え、手指で個別に掴む芝居は省ける。

## B案「並び直し」 — 46秒

**日常の目的**　商店街の小さな店で、顔見知りの客二人は互いに礼を尽くしながら買い物を済ませたい。店員は会計を進めたい。

**今回の異常**　店内で、目を合わせた相手に「お先にどうぞ」と声で言い切ると、話し手と相手の立ち位置が瞬時に入れ替わる。会話の向きは切り返しで表現し、カゴや商品はカウンターに固定する。立ち位置以外の変化はない。発生の終わりは画面外で、買い物が済んだ直後の最後の入れ替わりをオチにする。

| 時間 | 画・動作 | セリフ・演技 |
| --- | --- | --- |
| 00〜03秒 | レジ列の先頭に青い服の客、後ろに橙の服の客。青が振り向き、言い終わりで二人の位置が交換される。床の目印は動かない。 | B01 青「お先にどうぞ」ごく普通の会釈。 |
| 03〜11秒 | 前に立たされた橙は振り返って丁寧に譲り返す。青が再び先頭に来て、二人の目線が元の並びを追う。 | B02 橙「いえ、お先にどうぞ」戸惑いを笑顔で隠す。 |
| 11〜25秒 | やり直そうと二人が一回ずつ順に言い、交換が二度起こる。青は先頭に戻り、二人の会釈だけが深くなる。店員はカゴを触らず待つ。 | B03 青「お先にどうぞ」先に相手を通したい。B04 橙「お先にどうぞ」ひるまず返す。 |
| 25〜37秒 | 店員が青の品を手元でスキャンし、青が会計を済ませる。橙は安心して後ろで待つ。 | B05 店員「青い上着のお客さま、こちらへ」普段の接客。B06 青「ありがとうございます」ようやく肩が下がる。 |
| 37〜46秒 | 店員が袋をカウンターに置く。青は照れ隠しで反射的に店員に会釈。床の目印とレジの位置は同じまま、青が店員側、店員が列側に立つ。橙は青にカゴを差し出す。 | B07 青「お先にどうぞ」言い終えてから気づく。B08 橙「じゃ、これお願いします」通常の買い物の声。青の困り顔で切る。 |

**感情の流れ**　青は善意 → 混乱 → 解決の安堵 → 再発の気まずさ。橙は遠慮 → 張り合い → 自然な受け入れ。店員は一貫して淡々。最後は同じ言葉と目線が作用する相手を変え、異常のルールを保ったまま日常の役割を入れ替える。

**概算素材**　レジと二人分の列の目印を含む背景1枚、キャラ3体、固定のカゴ・商品・袋・レジ各1、POS音1種。優先差分は会釈・振り向き・困り顔・カゴを前に出すポーズ。位置交換は同じ画角での座標切り替えを基本とし、青・橙の色は識別用の仮色とする。
