# EP001 脚本再設計 v1.3 C案｜友人の生配信で検証成功

**G1未承認・比較候補。** 44秒／Shorts 9:16。「友人宅への再接続」が実は友人の撮影ネタになる、現代的なメタコメディ。既存G1 v1.2／PR #18、既存素材は保持。

## 各案共通の現象ルールと0–24秒
「行けたら行く」と誘いへの返信で送ると、**玄関の戸枠の向こうだけ**が指定された実在の誘い先につながる（本人は自動移動しない）。「遠い」「部屋着」の追加口実はその経路・受入条件を調整する。明確な「今日は行かない」で接続は解除。別の誘いへの再送信なら新しい別接続を開く。タイムトラベル・分身・招待先の生成は発生しない。友人は元の場所におり、玄関からこちらを見て初めて話す。仮の本話用設定でありシリーズ全体の確定ルールではない。

## 効くポイントと制作コスト
- 設定はあくまで戸口が友人宅につながるだけ。配信は**友人が事前に自分で行っていた通常行為**で、異変が動画配信を生じさせたわけではない。
- 追加：友人宅の一角、友人胸上、スマホ／簡易三脚、汎用LIVE表示と手の向き、主人公の羞恥表情。実在サービス名・ロゴを用いない。
- **弱点**：画面内スマホに文字が小さく詰まる。赤いLIVEだけで意味が分かる画を優先し、コメントは一瞬でも可能。友人が撮影を始めた事情の説明は入れない。
