# EP001 完成まで継続する Codex Goal（起動用）

Codex 0.128.0 以降で Goals が利用できる環境を想定する。これは起動指示であり、ファイルを置いただけで自動起動はしない。

## 起動コマンド（Codex の会話欄）

```text
/goal docs/prompts/complete_ep001.md に従い、最新の承認済み企画 EP001「行けたら行く」が通じない日を、正式な作画・日本語の採用音声・演技・字幕付きの完成候補MP4と全編QC証拠まで制作する。総監督が4担当へ委譲し、未完了なら次の実行可能な工程へ進み、修正と再検証を繰り返す。既存の承認ゲートを守り、課金・正式デザインの未承認確定・無断マージ・公開は禁止。真のブロッカーでは進捗と必要な承認を記録して停止する。
```

ゴールを設定する前に下記を読み、適用対象のPRを最新状態で確認する。Goalsが利用できない場合はこの文書を一度の通常指示として与え、実行できる範囲まで進め、継続時に進捗記録を読み戻す。独立したチャットの定期監視は主たる実行手段としない。

- 制作対象は **EP001のみ**。新しい話の企画や汎用オーケストレーター開発は後回し。
- 2026-11-22時点の現企画は「行けたら行く」が通じない日（約35秒・縦型・G0承認の記録はPR #18に提出）。総監督が最新の決定ログとオーナーの承認記録を照合する。
- PR #18：G1脚本。#19：正式デザイン候補の作画QC、#20：EP001素材要求、#21：技術試作、#22：演出試作。#13は旧企画、#8は旧作画候補。番号は開始時の索引で、後継PRや最新承認を優先する。
- PR #12の会話中心リミテッドアニメ方針と、#14/#16/#17で採用済みの作画QC・制作フローを照合する。決定IDの重複は総監督が解消し、承認記録を上書きしない。
- AGENTS.md、docs/decisions.md、docs/series_bible.md、docs/production_workflow.md、docs/production_rules.md、docs/review_rules.md、docs/agent_orchestration.md と各担当の agent.md・review_checklist.md を読む。
- 既存の人間・他チャットが進めているPRの成果を利用する。作業所有者・参照SHAを確認し、同一ファイルの同時編集、他担当の作業の無断置換、強制pushをしない。

## 2. 実行ループ

親セッションは総監督。既存の script_director、art_director、direction_director、video_director を必要なときに起用する。起動できない環境ではその事実を記録し、親が許可された範囲で作業を直列化する。サブエージェントの起動成功を推測で報告しない。

1. 最新のmainと対象PR・レビュー・成果物・承認を確認し、進捗表を更新。
2. ゲートごとに実行可能な作業を選ぶ。独立タスクのみ並行化する。担当・入力SHA・出力パス・QC条件を与える。
3. 結果を回収し、総監督が実物とログを確認する。合格は既存ルールで権限を持つ承認者が判定する。未承認成果物は候補と明示する。
4. 不合格は時刻／カット／素材ID、現状、期待値、修正担当を明記して再委譲する。同じ失敗を反復する場合は原因と別の修正方法を検討する。
5. あるゲートで人間の判断を待つ間は、それに依存しない準備・検査を進める。未承認の工程を本制作扱いにしない。
6. 次に行う実作業がある限り、報告のみで完了にしない。証拠を保存し、Goalの完了条件と照合する。承認待ち・利用上限・権限不足・素材不在などで実行可能な作業がなくなった場合は停止する。

## 4. 完了条件（公開ではなく完成候補）

すべてが根拠付きで揃ったときにのみ Goal を完了とする。

- [ ] G0/G1/G2a/G2b/G2/G3/G4 の承認証拠。G5用の提出資料。
- [ ] 正式デザインの原画・各カットに必要な素材と台帳、並列目視比較・動作QC。
- [ ] 日本語の採用セリフ音声、感情・読み・話者の試聴、権利確認。試験音や字幕のみは不可。
- [ ] Shorts完成候補MP4：1080×1920、作品内で24/30fpsに統一、H.264/AAC、最終音声48kHzステレオを基本とする。尺は承認台本・実測音声に従う。
- [ ] 全編デコードと実際の全編視聴・試聴。代表フレームだけで絵・演技・音声全体を合格としない。
- [ ] 実機相当の字幕安全領域、題材の分かりやすさ、オチの間、必要な手足・表情、口パクを確認。P0/P1の未解決を残さない（例外は既存規則に従う）。
- [ ] 完成動画の実際に取得できる保管先・版・SHA256、素材原本、再生成手順、QC証拠、関連PRを記録。動画がないのに完成や納品を宣言しない。
- [ ] 総監督の最終評価、および未公開の明記。G5公開承認・YouTube投稿はGoalのゴール外。

## 5. ブロック・再開

進捗は EP001 の統合PR（既存PRまたは新規の明確な統合PR）に記録する。頻繁な分散コメントではなく、更新時の版とQC証拠をまとめる。テンプレート：[進捗チェックポイント](../ep001_checkpoint_template.md)。

実行環境・使用枠・画像生成・音声API・原画の受け渡し・承認が不足した場合は、ブロックされた作業だけを止める。同じ失敗を無限に繰り返さない。残る独立作業がなければ、どの承認者が何を承認すれば再開できるかを報告する。費用の増加や権限昇格、設定の勝手な変更で回避しない。

Codexの `/goal` で状態を確認し、`/goal pause` で停止、必要な判断を入力したのち `/goal resume` で再開、`/goal clear` で解除する。Goalの継続は利用可能な実行環境、セッション状態、利用枠、ブロッカーに依存する。PC停止後の動作や常時無人稼働は保証しない。
