# 『もしも区の日常』作画監督向けキャラクターデザイン・アニメーションパーツ仕様書

- **版**：v0.1（デザイン案・未承認）
- **作品名**：『もしも区の日常』（仮）
- **ジャンル**：日常・SFコメディ
- **映像形式**：YouTube Shorts（縦型）／長尺（横型）
- **作画方針**：デフォルメしたコメディアニメ風、2Dカットアウト＋パーツ差し替え

> 本資料のキャラクター名・容姿・色は仮案。作画監督が設定画を提案し、総監督の承認後に正式設定とする。

---

## 1. 全体アートルール

### 1-1. 画風

- **頭身**：3.5〜4頭身
- **対象イメージ**：かわいい寄りだが幼すぎない、若年〜一般層向け
- **線**：やや太めで均一。小さいスマホ画面でも輪郭を識別できる
- **形**：ディテールを増やしすぎず、シルエットで人物を識別できる
- **影**：セル調1段影を基本とし、必要に応じ頬・髪の補助影を加える
- **演技**：顔・眉・口に加え、頭の傾き、体の前傾・後傾、腕の動きを用いる
- **構造**：パーツ分けしやすいシンプルな髪・服の形を優先する
- **制作目標**：Shortsでの視認性と、長尺での継続的な演技の両立

### 1-2. 配色

- 主人公3人は配色だけでも区別できること
- 背景に埋もれない、明快すぎず中彩度の色を採用
- SFエフェクトが重なるため、服に蛍光色を多用しない
- カラー設定は通常光を基準に統一する

### 1-3. アニメーション方式

- **基本**：2Dカットアウト＋差し替え式（Live2D風の連続変形は必須としない）
- **顔**：目・眉・口の差し替え、頬染め・汗・涙などのオーバーレイ
- **体**：頭と胴体の回転、上下移動、手・腕・脚の差し替え
- **重要シーン**：感情の変化に合わせて専用ポーズや構図を追加
- **優先事項**：毎秒多く動かすことより、感情やセリフと動きの整合性

### 2-1. 宮瀬 ナオ（仮）

**コンセプト**：「普通でいたいのに、普通でいられない男」

- **年齢感**：20代半ば
- **職業**：在宅寄りの会社員
- **性格**：まじめ、心配性、責任感が強い、面倒見が良い
- **役割**：異常現象にまじめに対処しようとして、一番ひどい目に遭うツッコミ役

**外見案**

- 髪：短め、少しだけ跳ねる前髪
- 顔：丸すぎず、やや縦長寄りのデフォルメ
- 目：半目・ジト目が似合う、やや大きめの目
- 服：ライトベージュ／グレー系の上着、白インナー、ダークパンツ
- シルエット：肩幅やや狭め、細身。派手さを抑えた「普通」の印象
- 配色：ベージュ／アイボリー、ダークグレー、くすみブルー少量

**重点表情**

- 困惑
- ツッコミ怒り
- 呆れ
- 諦め
- 照れ隠し
- 強い焦り

**重点演技**

- 頭を抱える
- 前のめりでツッコむ
- 肩を落とす
- 片手を上げて止める
- 眉間にしわを寄せる

### 2-2. 天野 ヒビキ（仮）

**コンセプト**：「面白そうなら、とりあえずやる女」

- **年齢感**：20代半ば
- **職業**：配達員
- **性格**：明るい、楽天的、大胆、好奇心旺盛
- **役割**：異常現象を試して事件を大きくする起爆剤

**外見案**

- 髪：短め〜ミディアム、跳ね感あり
- 顔：丸顔寄り
- 目：大きく、リアクションに適した形
- 服：動きやすいジャケット、インナーTシャツ、細身パンツ、またはショート丈＋レギンス
- 小物：必要に応じて小さな配達バッグ
- シルエット：軽快で元気。大きな手振りが映える
- 配色：オレンジブラウン系の髪、ターコイズ／オレンジ／明るいネイビーの服、黄色のアクセント

**重点表情**

- キラキラ期待顔
- ドヤ顔
- 悪だくみ顔
- パニック顔
- しょんぼり
- 目を輝かせる顔

**重点演技**

- 両手を大きく広げる
- 身を乗り出す
- 跳ねる
- 指差し
- ガッツポーズ
- 急停止して固まる

### 2-3. 久住 スズ（仮）

**コンセプト**：「動じないのに、たまに一番変」

- **年齢感**：20代後半
- **職業**：喫茶店勤務
- **性格**：落ち着いている、観察好き、乾いたユーモアがある
- **役割**：冷静な第三の視点、ときどき核心を突くオチ担当

**外見案**

- 髪：肩くらいの、整いすぎないストレート
- 顔：やや面長寄り
- 目：半目ベースにしやすい形
- 服：カーディガン、またはエプロン付きの喫茶店服
- シルエット：縦にすっとした、落ち着いた印象
- 配色：ダークブラウン／黒髪、ラベンダーグレー／くすみ紫／黒／濃いベージュの服、深い赤またはくすみブルーのアクセント

**重点表情**

- 無表情
- 半笑い
- わずかな驚き
- 面倒そうな顔
- 優しい微笑み
- 本気で困る顔（使用頻度は低め）

**重点演技**

- 首をわずかに傾ける
- 視線だけを動かす
- カップを持つ
- 小さくため息をつく
- 毒舌時に静かに笑う

## 3. 3人の構図・演技バランス

- **2人の掛け合い**：ナオ × ヒビキを基本にする
- **オチや第三の視点**：スズが追加の一言を入れる
- **3人並び**：基本候補は中央ナオ、左右にヒビキとスズ

- **ヒビキ**：大きな身振りと瞬間的な動作で画面を動かす
- **スズ**：最小限の動きと間の取り方で印象を残す

## 4. アニメーション用パーツ納品仕様

### 4-1. 形式と解像度

- **各パーツ**：透過PNG（RGB/RGBA）
- **マスターデータ**：レイヤーを保ったPSDを推奨
- **キャラクターごとにフォルダを分ける**
- **長尺用マスター**：全身立ち絵の縦約2000pxを目安とする
- **Shorts用**：顔のクローズアップでも輪郭が破綻しない解像度とする
- **命名**：英小文字の一貫した規則で保存する
- **重要**：関節の重なり部分は、回転時に隙間が生じないよう見えない範囲まで描き足す

### 4-2. 共通基本パーツ

| 領域 | 必須パーツ |
|---|---|
| 頭部 | 頭、前髪、後頭部／後ろ髪、必要に応じて首 |
| 胴体 | 胴体、必要に応じて服の前面パーツ |
| 左右の腕 | 上腕、前腕、手を左右別に分割 |
| 左右の脚 | 太もも、すね、足を左右別に分割 |
| 顔 | 左右の目、左右の眉、口、頬チーク |
| 感情オーバーレイ | 汗、青ざめ、影、涙、怒りマーク、驚き線 |

### 4-3. 目パーツ：最低8種

1. 通常開き
2. 少し細め
3. 半目
4. 閉じ目（笑顔）
5. 閉じ目（真顔）
6. 驚き見開き
7. ジト目
8. 泣き目

**キャラ別追加**

- ナオ：困惑目、白目気味の焦り目
- ヒビキ：キラキラ目、ドヤ目
- スズ：眠そうな目、わずかに笑う目

### 4-4. 眉パーツ：最低7種

1. 通常
2. 上がり（喜び）
3. 下がり（困り）
4. 怒り
5. ハの字（悲しみ）
6. 驚き
7. 片眉上げ

### 4-5. 口パーツ：最低10種

1. 閉じ口（真顔）
2. 閉じ口（笑み）
3. 横開き・小
4. 横開き・中
5. 横開き・大
6. 縦開き・小
7. 縦開き・大
8. O口・小
9. O口・大
10. への字／不満

**追加候補**：歯見せ笑い、ニヤリ、叫び口、泣き口

**リップシンクの簡易対応**

- M（閉じ）
- A
- I
- U
- O

> 「M/A/I/U/O」は初期制作用の簡易カテゴリ。日本語の厳密な口形同期や感情表現には追加差分を用いる。

### 4-6. 腕ポーズ：各キャラ最低6種

1. 下ろし
2. 軽い会話
3. 指差し
4. ツッコミ／強調
5. 顔前リアクション
6. 腰当て／たたずみ

**キャラ別追加**

- ナオ：頭を抱える、止める手
- ヒビキ：両手広げ、ガッツポーズ、突進前傾
- スズ：カップ持ち、片手添え、腕組み

### 4-7. 手パーツ：左右それぞれ最低5種

- 通常開き手
- 軽く握る
- 指差し
- こぶし
- 物を持つ手

### 4-8. 脚パーツ／動作

- 通常立ち
- 片足重心
- 軽い歩き1・2
- 走り簡易1・2
- 座り用（必要なら別立ち絵）

## 12. 作画監督への正式依頼文

### 依頼概要

『もしも区の日常』のメイン3キャラクターについて、**3.5〜4頭身のデフォルメしたコメディアニメ風デザイン**を制作してください。YouTube Shortsと長尺動画の両方で使用する前提です。感情表現が大きく、視認性が高く、2Dカットアウトアニメに適したパーツ構造を重視してください。

### 必須要件

- 3人のシルエット差を明確にする
- 配色で即座に識別できる
- 顔の演技が強い
- パーツ分けしやすい
- 3/4向きを基本に、会話演技に強い構成にする
- 日常コメディ中心だが、感動・シリアスにも対応できるデザインにする

### 納品希望

- キャラクター設定画
- 正面・3/4左右の立ち絵
- 表情セット
- 口・目・眉の差分
- 腕・手差分
- 全身ポーズセット
- 透過PNGとレイヤー付きPSDマスター

### 承認ポイント

- Shortsのスマホ画面で見やすいか
- 3人が並んだときシルエット・配色で識別できるか
- 声の感情に合わせて表情・ポーズを切り替えやすいか
- 長尺動画で再利用できるパーツ構造になっているか
