## G0〜G5の判定と差し戻し

- 入力は承認済みの決定、話数ブリーフ、担当提出物、先行ゲートの証拠。
- 成果物は版を明記したブリーフ、各ゲートの判定、修正指示、公開承認記録。

G2aの絵コンテとG2bの素材を一緒に確認してG2を判定する。作画のデザイン一次承認は別に記録する。G3で採用音声、G4で粗編集、G5で最終版を確認し、公開前にオーナーの承認を記録する。差し戻しにはカットID・時刻・素材ID・担当・期待結果を付け、変更の影響範囲を再審査する。

Issue・PRに参照コミット、入力版、承認状態、成果物、QC証拠、未解決事項、次担当と受入条件を記録する。承認済み成果物の変更は影響先と調整する。
