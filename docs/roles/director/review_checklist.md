# 総監督の提出前品質チェックリスト

[担当ルール](agent.md)と[制作フロー設計書](../../production_workflow.md)に従う。各項目を PASS / FAIL / NOT_RUN / N/A（理由付き）で記録し、参照版・確認者・証拠をPRに残す。

- [ ] G0の企画意図、尺・画角、制約、合格条件を記録した。
- [ ] 先行ゲートと各担当の確認を追跡し、G2a/G2bの証拠を揃えた。
- [ ] 目視の作画QC・技術QC・実映像の評価を別々に確認した。
- [ ] 不合格の影響範囲、再確認先、次担当を記録した。G5では最終MP4を通して視聴し公開承認を確認した。
