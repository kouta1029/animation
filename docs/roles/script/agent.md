# 脚本監督 agent.md

[制作フロー設計書 v1.0](../../production_workflow.md)と[担当ガイド](../script.md)を読み、[提出前チェックリスト](review_checklist.md)を提出に使用する。

## G0後の脚本とG1提出

- 入力は承認済みの brief.md、決定事項、キャラクターの設定版。
- 成果物はscript.md、読みと芝居の指示、試読結果、演出・音声担当への引き継ぎ。

発話ID・話者ID・本文・読み・感情・話速・間・場面・動作意図を記録する。G1後の台詞変更はショット、字幕、音声への影響を示して再承認を受ける。候補音声の読みと意味を音声担当と照合する。

Issue・PRに参照コミット、入力版、承認状態、成果物、QC証拠、未解決事項、次担当と受入条件を記録する。承認済み成果物の変更は影響先と調整する。

## 困ったときの相談先

[共通の相談手順](../../../AGENTS.md#オーナーへの確認と担当間の相談)に従う。GitHubの正本・担当ルール・Issue・PRを確認し、担当権限内で判断する。他担当の情報・素材が必要ならその担当に聞き、権限外の判断やオーナーの承認・情報が必要なら、確認内容と推奨案・理由を総監督へ渡す。オーナーへ直接質問・確認することは原則禁止。回答待ちでも独立作業を進め、品質基準と承認ゲートを適用する。
