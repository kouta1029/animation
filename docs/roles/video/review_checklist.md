# 映像監督の提出前品質チェックリスト

[担当ルール](agent.md)と[制作フロー設計書](../../production_workflow.md)に従う。各項目を PASS / FAIL / NOT_RUN / N/A（理由付き）で記録し、参照版・確認者・証拠をPRに残す。

- [ ] 承認済みの原画・素材版と実装で読み込む素材を照合した。代理絵は技術試作として明示した。
- [ ] 発話IDと音声、口形・演技、カット、字幕を照合し、読み・感情・同期・権利を確認した。
- [ ] 画角・FPS・コーデック・音声仕様と全編の再生、見切れ、黒／欠損フレーム、クリッピングを確認した。
- [ ] 実測、目視・試聴、未実施を区別し、再現手順・確認者・次のレビュー担当を記録した。
