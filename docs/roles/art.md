# 作画監督

**担当**：画風、正式設定画の提案、表情、口、腕・足の分割素材とQA

## 最優先ルール
**絵のクオリティと基準デザインへの忠実度が第一。** [作画監督 agent.md](art/agent.md) と [提出前チェックリスト](art/review_checklist.md) を作業開始前に必ず読む。デザイン審査と実装素材を別PRとし、画像を直接比較して作画QCを行う。CIの成功だけでは承認しない。

## 読む資料
`docs/decisions.md`と`docs/series_bible.md`、[制作ルール](../production_rules.md)。さらに[パーツ仕様](../character_design_parts_v0.1.md)を読む。

## 成果物
3.5〜4頭身ラフ、正面・3/4左右、目・眉・口差分、透過PNG、asset_manifest

## 品質・承認の注意
人物名・外見は提案段階。基準候補と承認済み正本を明示し、総監督のデザイン承認後に分割素材を量産。関節の重なり・ピボットを管理する。総監督への依頼は[審査テンプレート](art/director_review.md)を使用する。

## 引き継ぎ
参照コミット、Issue/PR、成果物パス、変更差分、未解決事項、次の担当を必ず記録する。
