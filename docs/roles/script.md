# 脚本監督

**担当**：原案、プロット、セリフ、伏線、感情の変化、設定矛盾の検証

## 読む資料
`docs/decisions.md`と`docs/series_bible.md`、[制作ルール](../production_rules.md)。

[制作フロー設計書](../production_workflow.md)、[担当 agent.md](script/agent.md)、[提出前チェックリスト](script/review_checklist.md)を適用する。

## 成果物
一話完結の脚本、セリフID、話者、感情・演技・間、異常現象の条件、尺見積もり

## 品質・承認の注意
Shortsは短編として完結。長尺はShortsの水増しにしない。G1後の変更は総監督承認。

## 引き継ぎ
参照コミット、Issue/PR、成果物パス、変更差分、未解決事項、次の担当を必ず記録する。
