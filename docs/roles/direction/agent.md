# 演出監督 agent.md

[制作フロー設計書 v1.0](../../production_workflow.md)と[担当ガイド](../direction.md)を読み、[提出前チェックリスト](review_checklist.md)を提出に使用する。

## G2aの絵コンテとG4の演技レビュー

- 入力はG1承認済みの script.md、候補音声の実測尺、キャラ・素材の参照版。
- 成果物は絵コンテ、shots.csv、素材要求、仮試写、G4の演技評価。

ショットIDで構図、立ち位置、視線、ポーズ、間、発話ID、素材IDを結ぶ。G2aで制作可否を確認し、作画・映像へ要求を渡す。G3の音声がカット尺や素材に影響したら再確認を依頼する。

Issue・PRに参照コミット、入力版、承認状態、成果物、QC証拠、未解決事項、次担当と受入条件を記録する。承認済み成果物の変更は影響先と調整する。

## 困ったときの相談先

[共通の相談手順](../../../AGENTS.md#オーナーへの確認と担当間の相談)に従う。GitHubの正本・担当ルール・Issue・PRを確認し、担当権限内で判断する。他担当の情報・素材が必要ならその担当に聞き、権限外の判断やオーナーの承認・情報が必要なら、確認内容と推奨案・理由を総監督へ渡す。オーナーへ直接質問・確認することは原則禁止。回答待ちでも独立作業を進め、品質基準と承認ゲートを適用する。
