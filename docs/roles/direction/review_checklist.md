# 演出監督の提出前品質チェックリスト

[担当ルール](agent.md)と[制作フロー設計書](../../production_workflow.md)に従う。各項目を PASS / FAIL / NOT_RUN / N/A（理由付き）で記録し、参照版・確認者・証拠をPRに残す。

- [ ] 全カットにショットID、尺、画角、演技、発話ID、必要素材を記録した。
- [ ] 候補音声の実測尺で間とリアクションを検討し、仮尺を明示した。
- [ ] 冒頭の可読性、視線と動線、表情のピーク、字幕や大事な絵の見切れを試写で確認した。
- [ ] G2a確認と素材要求、G4での時刻付き修正箇所を作画・映像・総監督へ共有した。
