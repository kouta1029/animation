# 総監督への作画審査依頼テンプレート

作画監督の [agent.md](agent.md) と [review_checklist.md](review_checklist.md) に従い、作画自己QCを通過した資料だけを審査依頼する。

## デザイン一次審査
- 対象Issue／PR：
- 参照コミット：
- 基準候補画像の実在するリンク・版・出典：
- 新しい設定画（正面／左3/4／右3/4）：
- 参照と成果物を並べた比較画像（原寸・128px）：
- 表情見本・配色・非対称情報：
- 制作方法・作画QC評価と証拠：
- 技術QC（別判定）：
- 変更点・未解決事項：
- 総監督に判断してほしいこと：

審査結果は記入者・コミット・画像版を伴い、次から選ぶ：採用／修正要求／保留。採用範囲と変更条件を記録してから実装素材へ。デザイン一次承認はG2最終承認ではない。

## G2最終審査
- 承認済みデザインの版・承認記録：
- 対象の絵コンテ・ショットID・素材ID：
- 原画と分割素材の再合成比較：
- 作画QC／技術QC／実装動作検証の個別結果：
- 演出・映像監督の確認結果：
- 残課題と承認範囲：

総監督が既存の制作ゲート規則に基づいて判定する。未承認事項は未承認として引き継ぐ。
