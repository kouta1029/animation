# 作画監督：提出前品質チェックリスト v1.0

[作画監督ルール](agent.md) に従う。PRごとに結果・確認者・参照コミット・証拠パスを転記。各項目は PASS / FAIL / NOT_RUN / N/A（理由）で記録し、未実施を合格扱いしない。

## A. 入力と正本
- [ ] 実際の参照画像を開いた。画像の実在するパス／アクセス可能なURL、版、承認状態、出典・権利を記録した。
- [ ] 今回の成果物の画像ファイル・版と参照画像が対応している。基準候補と承認済み正本を区別した。
- [ ] 制作手法・使用モデル・画像参照の有無を記録した。未確認の画像生成・編集を実施済みとしない。

## B. デザイン／画のクオリティ（実画像目視必須）
- [ ] 基準画像と新作画の正面・左3/4・右3/4を並べた比較画像を実際に確認した。
- [ ] 顔の形、目・眉・口、髪の形とボリューム、身長比・頭身・身体の輪郭が一致する。
- [ ] 衣装の形・色・柄・装飾・靴・小物が一致し、身体の左右（非対称要素）を取り違えていない。
- [ ] 線の太さ・質、影の処理、配色と情報量、アニメとしての魅力を損なっていない。
- [ ] 3方向の遠近・顔と体の向きが自然。単純な鏡像で非対称要素をごまかしていない。
- [ ] 通常・笑い・驚き・困惑・怒りなど、必要な表情が同一人物に見え、読み取れる。
- [ ] 原寸で破綻・欠け・ノイズを確認。3人の同じ背景・表示高約128pxの比較で識別性を確認（縮尺、表示高、背景の記録）。
- [ ] 画質の劣化や別デザイン化がない。差異がある場合は許容理由ではなく、修正または再承認対象を記述。
- [ ] 実画像を確認できない場合は NOT_VISUALLY_REVIEWED とし、デザイン審査を依頼しない。

## C. 分割・リグ素材（実装素材PRのみ）
- [ ] 総監督が承認した設定画・版・承認コメントを参照した。
- [ ] 原画からの切り出し／必要な補描で制作し、再合成プレビューと基準原画を並べて見た。
- [ ] 透過のフチ、線幅、色、隠れた関節、描画順、回転時の隙間・遮蔽を確認した。
- [ ] 実在する素材とマニフェスト、ピボット、原画ID、版が対応している。空・代理パーツは明示し有効数から除外した。
- [ ] 映像監督と代表カットの動作を確認した。未確認なら NOT_RUN とし、G2最終審査の残作業として明記。
- [ ] 原画との不一致が残る状態で正式素材の参照先を切り替えていない。

## D. 技術検査・提出
- [ ] 実在／ファイル形式／寸法／アルファ／非空／参照を検証した（実施コマンドと結果を記録）。
- [ ] 作画QCと技術QCを別欄で判定。CI成功を作画合格の根拠にしない。
- [ ] 公開リポジトリの素材権利・生成元・保管先を確認した。
- [ ] 適切なPRテンプレート、変更内容、未実施、レビュー先を記載した。
- [ ] 総監督の正式承認と自己QCを混同せず、承認前にmainマージしない。

## 判定記録
| 項目 | 判定 | 証拠（画像パス・コメント・ログ） | 不合格理由／対応 |
| --- | --- | --- | --- |
| 正本確認 | NOT_RUN | | |
| 作画QC | NOT_RUN | | |
| 技術QC | NOT_RUN | | |
| 実装／動作QC | NOT_RUN | | |
| 総監督デザイン承認 | 未承認 | | |
| G2最終承認 | 未承認 | | |

実画像の確認・比較証拠・忠実度にブロッカーがあれば「作画QC FAIL／NOT_RUN・Draft維持」。技術QC合格だけでは解除しない。
