# 動き・演出の制作指針 v0.1

> **ユーザーが決めた方向性**：キャラクターの動きは『マリマリマリー』のような、会話劇を中心にした**リミテッド2Dアニメーション**を参考にしてよい。
>
> **重要**：参考にするのは「限られた動きで会話と笑いを成立させる考え方」であり、同作品のキャラクター、絵柄、衣装、背景、音楽、台詞、独自の画面レイアウトを複製しない。

## 1. 作品への適用方針

『もしも区の日常』（仮）は「日常 × SFコメディ」。主役は普通の住民で、テンポのよい会話・異常現象への反応・間とオチで楽しませる。

- **通常会話**：全身を常時動かさず、口・目・眉・視線・首の傾き・少量の手の動きに絞る。
- **ツッコミや驚き**：表情差分、上半身の前傾、手のポーズ、大胆な顔の寄り、短い停止・再開で見せる。
- **話していないキャラ**：全員を同じ周期で揺らさない。聞き役の目線や一瞬の反応だけを必要な場面で入れる。
- **間とオチ**：動作を止める／無表情アップ／対比する引き画などで演出する。静止している理由を設計する。
- **SF現象**：通常の会話では省力化し、現象の発生・変化・転換点にアニメーションやエフェクトを集中させる。
- **長尺**：同じ立ち絵・同一背景・同一構図だけが何分も続かないよう、場所・相手・出来事・ショットを変化させる。

この設計は**自作品の試作規格**であり、『マリマリマリー』の内部制作工程や正確な使用枚数を断定したものではない。

## 2. 基本パーツ・動作（初期規格案）

| 種類 | 標準セット | 主な用途 |
|---|---|---|
| 口 | 閉・A/I/U/O＋笑い・叫び | セリフ・感情 |
| 目 | 通常・半目・閉・驚き・ジト目など | 聞き役・ツッコミ |
| 眉 | 通常・怒・困・驚・片眉など | セリフのニュアンス |
| 頭・首 | 前後傾、左右傾き、視線変更 | 相づち・疑問・呆れ |
| 腕・手 | 下ろし・指差し・ツッコミ・腕組み等 | コメディのアクセント |
| 全身 | 立ち姿勢、重心移動、短い歩き | 導入・退出・場面転換 |
| コメディ差分 | 白目、汗、硬直、青ざめ、誇張ポーズ | 笑いのピーク |

**実装推奨**：2Dカットアウト＋パーツ差し替えを基本とする。手間を減らすことより「何を動かすと面白いか」に時間を使う。

## 3. 絵コンテ・カメラのルール

- 台本の`line_id`に合わせ、ショット`shot_id`を作成する。
- **基本ショット**：2ショット（関係性）、話者バストアップ（セリフ）、聞き役リアクション（オチ）、物やSF現象のクローズアップ。
- カットの切り替えは**意味のある感情・情報・視点の変化**で行う。機械的な「数秒ごと切替」は必須にしない。
- オーバーリアクションは重要な台詞に限定する。全部の台詞を大声・派手な動作にしない。
- カメラ・手・顔・字幕が同時に大きく動きすぎないよう視線誘導を意識する。
- Shortsは9:16・スマホUI領域を考慮。長尺は16:9・場面転換やBストーリーで単調さを防ぐ。

## 4. 音声が先、演技は同期

- 生成した声の**実尺・感情・間**を測定し、セリフに対する口・目・頭・手の動きのタイミングを設定する。
- ElevenLabs、VOICEVOX、AivisSpeechは比較中。声の選択を前提に演技を固定しない。
- 「笑いながら言う」「呆れて小声」「1拍固まってから叫ぶ」などの表現は声と画の両方を連動させる。
- 全発話を口の音量連動だけで済ませない。母音/音素同期や手動の重要ポイント調整を必要に応じて使う。

## 5. 担当別の依頼事項

| 担当 | 反映すること |
|---|---|
| 脚本監督 | ツッコミや無言の間をセリフ・演技指示に含める |
| 作画監督 | 3.5〜4頭身の独自シルエットと、少ないパーツで感情を伝える差分を優先 |
| 演出監督 | セリフごとにショット、リアクション、停止、カメラの意味を明記 |
| 映像監督 | 差分アニメと音声同期を再現可能なシステムで実装し、プレビューでQA |
| 総監督 | 「動きが少ない＝低品質」ではなく、笑い・間・視認性・テンポで評価 |

## 6. パイロット動画の受入チェック

- [ ] 冒頭で異変がすぐ伝わる
- [ ] 会話の主役と聞き役が見分けられる
- [ ] キャラの感情と声・表情・身振りが合っている
- [ ] 静止・切り返し・リアクションに意図がある
- [ ] 口パク・字幕・音声に明らかなズレがない
- [ ] 重要なSFの見せ場には必要な動きがある
- [ ] 参考作品の絵柄や固有表現に寄せず、独自のキャラデザインが維持されている
