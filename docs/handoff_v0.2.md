- 対象：『もしも区の日常』初期キャスト3人
- 入力：総合設計書v1.0、キャラ/パーツ仕様書v0.1
- 作業：正面キャラ、共通座標の分割SVG、透過PNGと10表情プリセットを自動生成
- 状態：**未承認デザイン／本番用完成リグではない**

## 総監督への依頼
仮キャラ3人のシルエット・髪・服装・配色の評価、G2承認または差し戻しをお願いします。未承認デザインを既定値として正式に採用しないでください。

## 演出監督への依頼
EP001「全員が嘘をつけなくなった日」、EP002「重力が半分になった学校」のショット/演技表（時間、ポーズ、視線、表情、向き、画角、小道具）を引き継いでください。

## 映像監督への依頼
`build/art_v0.2/asset_manifest.json` のピボットと共通座標を試験利用。全パーツが元の600×1600 SVG座標を共有し、PNG書き出しは750×2000です。初期リップシンクカテゴリはM/A/I/U/O。頭と腕を回すときの隙間・レイヤー順・字幕安全領域の検査をお願いします。

## 現状の出来ることと出来ないこと
- **出来る**：3人の表情10種/人、目8種/人、眉7種/人、口10種/人を独立レイヤーとして生成してQAする。
- **未実施**：PSD、左右斜め向き、上腕/前腕/手分割、動作ポーズ、歩行/走行、背景、Godot/口パク本番検査、正式G2承認。

## 再生成
`python -m pip install -r requirements-art.txt`
`python tools/art/build_assets.py --output build/art_v0.2`
`python tools/art/qa_assets.py build/art_v0.2`
