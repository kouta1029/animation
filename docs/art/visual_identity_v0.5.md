# 作画部門｜独自絵柄のブランド設計 v0.5（G2前・候補）

**状態：DESIGN_CONCEPT / ART_QC_PARTIAL / 未承認。** 作品の正式な設定、配役、デザイン一次承認を変更しない。正本は [決定事項](../decisions.md)、[制作フロー](../production_workflow.md)、[作画品質ルール](../roles/art/agent.md)。

## 目的：ファンが「誰のどの作品か」覚えられる画作り

ファン獲得は保証できない。現状の仮説は、**3人の顔・髪・姿勢・アクセント色・リアクションが画面の小サイズでも即判別できる**ことと、**街角の日常にわずかなズレが起きるシリーズ共通の視覚記号**を作ること。視聴維持・サムネ反応・コメントにより後日検証する。

- 作画は独自の形状言語を発展させる。特定既存作品の固有キャラ・色遣い・衣装・演出の再現を指示しない。
- オーナー提供の画像 `1795304039191.png` を現在の**基準候補**として扱う。本人指定の参照から勝手に顔・衣装を変えない。
- ビジュアル開発の短い呼び名「**角のある日常、柔らかい人**」は内部コンセプトであり正式タイトルではない。

## 固有の作画言語（v0.5提案）

| 軸 | シリーズ共通仕様候補 | 禁止／注意 |
|---|---|---|
| 輪郭 | 濃紺〜墨紫のやや太い外形線、細部は線幅を絞る。直線・鋭角の服と柔らかい頬の対比を持たせる | 単純な図形アイコンへの置換、線の太さがカットごとに乱れること |
| 顔 | 顔の中心距離と顎の角度を固定。小さな目の中の四角いハイライト、少ない眉の動きで感情を読ませる | 「目を大きくすれば魅力が増す」の一律処理、口角の差を潰す |
| 色 | キャラの主色はナオ＝ベージュ×濃紺、ヒビキ＝青緑×橙×黄、スズ＝紫×臙脂。背景は夕方の柔らかい寒暖対比 | キービジュアルの夕焼けによる色変化を衣装の正式固有色に転写しない |
| 影 | キャラは基本ベース＋硬い影1段＋限定ハイライト。見せ場のキーアートでは局所的に情報を増やせる | 毎カットの複雑なグラデーション・細部ノイズを実装要件にすること |
| 髪 | ナオ＝高く跳ねた一本と本人左の二本留め、ヒビキ＝左右へ大きく広がる橙髪と黄色の大きな飾り、スズ＝垂直ボブと本人左の花飾り | 左右反転だけで非対称の小物まで逆側へ動かすこと |
| 動き | ナオ＝視線・眉・肩の小さな遅れ、ヒビキ＝大きな腕の弧と身体の傾き、スズ＝半目と静止からの小さい変化 | 全員に同じアイドルモーションをループさせること |
| 異変の記号 | 窓・戸口・フキダシなど、まっすぐな四角が**一辺だけずれる**形状をエピソードごとに少数使う | 重要な文字を邪魔する効果、毎カット何でも歪ませる表現 |
| 背景 | 普通の日常は固定形状・固定光源。異変は戸の奥、のれん、床目地等の限定範囲だけ変形 | 全背景を独立AI生成で差し替え、固定壁や床の形・光が跳ぶこと |

上の数値なしの規則は**提案**であり、線幅・基本画角・正規色を実際の承認画像に合わせて決定する。

## 人物別の認識フック

- **ナオ（主人公候補）**：高い跳ね毛＋二本ヘアピンと、感情をあまり出さない目。困惑時に「目を先に動かし、肩と手が遅れて反応」。普段着のメモ・名札は設定との整合を確認する。
- **ヒビキ（候補）**：外側に弾ける髪、黄色の飾り、青緑の上着。驚きは大きいが顔・帽子・ポーチ等の位置を雑に変えない。オリジナルの輪郭と演技で記憶させる。
- **スズ（候補）**：重いボブと小さな花飾り、紫の縦長シルエット、低い目線と半目。大きく動かない「間」が演技の特徴。
- 役名・職業・体型比・正式外見は総監督の別途決定前の仮案。

### 作画監督の自己QC

- **部分PASS（意匠の方向性）**：3人の髪と色のシルエットを踏襲。ナオのヘアピン、ヒビキの黄色飾り、スズの花飾りの基本位置が読める。ナオ＝無表情、ヒビキ＝大笑い、スズ＝静かな顔の役割差がある。
- **未達／修正必要**：キービジュアルでは暖色ライティングが強く通常の衣装色を定義できない。ナオの上衣・ヒビキの小物等が基準画像と細部不一致。右下の表情小コマは設定画としての角度・精度が不足する。全身3/4三方向・体格比・遮蔽・非対称再確認はNOT_RUN。
- **結論**：ART_QC_PARTIAL。絵柄仮説は検討可だが、正式設定画として一次承認請求不可。透過分割・リグ実装の着手を正当化しない。

## ファン獲得仮説の検証（動画公開後）

- 3人の輪郭だけをシルエット化し128pxで誰か分かるか、内部検査を最初に実施。
- サムネ案は「キャラ顔＋異変1つ」と「異変の物体寄り」を比較。比較時は内容・公開条件を可能な範囲で揃え、CTR・冒頭離脱・コメントを分析。初期少数データで成功を断定しない。
- 「髪型」「無表情ツッコミ」「紫の静かな反応」等、キャラ識別につながる自発コメントが見られるか定性的に検証。
- キービジュアルと動画本編では描き込み量を分けても、同じ顔・シルエット・線と影の法則を守る。

## 提出と承認の流れ

新規の高品質な**正面・左右3/4・表情・衣装**を基準PNGそのものを入力して再作画 → 原寸と128px（全身表示高）の目視QC → 総監督デザイン一次承認 → 必要カットの透過パーツ化 → 原画再合成比較・Godot検証 → G2判定。参考シートに存在する日本語ラベルや未承認タイトルは正本にしない。
